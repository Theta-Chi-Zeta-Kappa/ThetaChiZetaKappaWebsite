Website File Size Guide

Large files slow page loads and downloads, especially on mobile. These are review guidelines, not automatic rejection limits.

File typeWeb ReadyReview / CompressLarge File
PDF / document≤ 2 MB2–8 MB> 8 MB
JPG / WebP≤ 500 KB500 KB–2 MB> 2 MB
PNG≤ 1 MB1–3 MB> 3 MB

PDFs: Use a web-optimized copy when possible. Keep high-resolution print masters separately.

Images: Prefer WebP or JPG for photographs. Use PNG when transparency or lossless graphics are needed.

Approval: A large file is not automatically wrong, but the admin should confirm the extra size is justified before publishing.
